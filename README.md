## What Is Required for a Valid Experiment

To generate a quantitative finance experiment, the following are required:

1. **Hypothesis** — A clearly stated directional or statistical hypothesis
2. **Data Requirements** — Asset universe, time period, data frequency, data source
3. **Methodology** — Mathematical formulas, model specifications, signal generation logic
4. **Portfolio Construction** — Rebalancing rules, transaction cost assumptions, benchmark definitions
5. **Evaluation Criteria** — Performance and risk metrics, statistical significance thresholds
